PERSONAL RUNNING DATA

自分のランニング記録を、
クラウドで管理するために。

Running Cloud Pilotは、運用者本人のGarminデータと主観記録を整理し、非公開のGoogle Driveへ保存するための個人利用の移行試験です。PCを常時起動することなく、記録を継続して管理できる仕組みを検証しています。

現在は移行試験中です。取得内容の一致、認証の継続、保存結果を確認しています。このページで一般利用者の登録やデータの受付は行っていません。

このアプリが行うこと

  1. 本人が認可したGarminのアクティビティ・健康関連データと、指定された主観記録を読み取ります。
  2. クラウド上で原本FITやCSVを整理し、取得・変換・保存の結果を確認します。
  3. 本人の非公開Google Driveに、試験結果や分析用のファイルを保存します。

本人が分析を依頼した場合は、対象の記録をChatGPTなどの分析環境で処理することがあります。試験の実施と、本番運用への切替は別に判断します。

Googleへのアクセスが必要な理由

既存の入力ファイルをGoogle Driveから読み取り、作成した結果を試験用フォルダへ保存するため、本人のGoogleアカウントによる認可を利用します。

Googleの認可にはDrive全体を対象とする権限が含まれます。処理コードでは、あらかじめ指定した入力ファイルの読取りと、専用の試験用フォルダへの保存に用途を限定しています。OAuthの権限自体がフォルダ単位で制限されているわけではありません。

データの取扱い

記録は本人のデータ管理・移行検証・依頼された分析のために扱います。ランニングの実データや認証情報を、この説明サイトで公開することはありません。

Google Drive、GitHub Actions、本人が利用する分析サービスなど、処理や保存に関わるサービスと、認可の取消し・データ削除の方法はプライバシーポリシーに記載しています。

利用条件

Running Cloud Pilotは、運用者本人が自分の記録を管理し、クラウド移行を検証するための個人利用の試験です。一般利用者の登録や、他人のデータの受付は行っていません。

このアプリの役割は、データの取得・整理・保存・照合と、本人が依頼した分析の補助です。医療機関による診断や、医療・運動処方を提供するサービスではありません。試験結果は、実際に確認できた範囲と未確認の範囲を分けて扱います。

継続稼働、データの完全性、各連携サービスの利用継続、またはGoogle等の審査通過を保証するものではありません。Garmin、Google、GitHub、OpenAIとの公式な提携・認定を表すものでもありません。

データの取扱いは、プライバシーポリシーに従います。

運用者・お問い合わせ

このアプリは、GoogleのOAuth同意画面に表示されるアカウント所有者が、自分の記録を管理するために運用しています。お問い合わせは、OAuth同意画面のユーザーサポートメールへご連絡ください。

Running Cloud Pilotは個人が運用するアプリであり、Garmin、Google、GitHub、OpenAIの公式アプリではありません。
